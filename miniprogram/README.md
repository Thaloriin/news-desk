# 微信小程序端

## 怎么跑起来

1. 打开**微信开发者工具** → 导入项目 → 目录选 `E:\news-platform\miniprogram`
2. AppID 填你自己的（个人可免费注册）；没有就选“测试号”
3. 右上角「详情」→「本地设置」→ 勾选 **不校验合法域名**
4. 确保电脑上的服务在跑：`cd E:\news-platform && node server.js`
5. 小程序里进「设置」页，把接口地址改成 `http://localhost:8787`（真机调试要改成电脑的局域网 IP，例如 `http://192.168.1.10:8787`）

## 页面

| 页面 | 功能 |
|---|---|
| 首页 | 日期切换、分类标签、国家/地区筛选、按重要度排序的列表 |
| 详情 | 上原文下译文；点「翻译」调用服务端的 AI 翻译并缓存 |
| 设置 | 修改接口地址、查看数据统计 |

## 上线前必须做

微信小程序**不允许**请求 `http://` 和未备案域名。上线要做三件事：

1. 有一台公网服务器 + 已备案域名，用 Nginx 反向代理到本服务的 8787 端口，并配好 HTTPS 证书
2. 微信公众平台 →「开发管理」→「服务器域名」→ 把该域名加入 **request 合法域名**
3. `app.js` 里的默认地址改成该域名

## 接口依赖

小程序只用到三个接口：

- `GET /api/news`　列表（支持 day / category / country / limit）
- `GET /api/stats`　统计
- `POST /api/translate`　翻译单条（需要服务端配置了 AI Key）

管理接口（改 Key、开关数据源）**没有**开放给小程序，只在网页工作台里用。
